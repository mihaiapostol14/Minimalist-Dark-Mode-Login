## Overview
This project is a minimalist dark mode login interface designed to provide an aesthetically pleasing and user-friendly experience for users needing to log into their accounts. The interface is responsive and works seamlessly across various devices.

## Preview
![Minimalist Dark Mode Login Preview](https://github.com/mihaiapostol14/Minimalist-Dark-Mode-Login/blob/4428af8bd963d74cba841e8619ab6eb23c494621/assets/preview.png)


## Tech Stack
- **HTML** - For structuring the web page.
- **CSS** - For styling the interface with a dark mode theme.
- **JavaScript** - To handle user interactions and form submissions.
- **Bootstrap** - For responsive design and ready-to-use components.

## Clone the repository
```bash
git clone https://github.com/mihaiapostol14/Minimalist-Dark-Mode-Login.git
cd Minimalist-Dark-Mode-Login
```
**Open the index.html file** in your web browser to view the login interface.

## Features
- **User-friendly design** that is visually appealing and easy to use.
- **Dark mode** enhances usability in low-light environments.
- **Responsive layout** ensures compatibility with desktop, tablet, and mobile screens.
- **Form validation** to guide users in entering valid credentials.
